# Bouncing Rainbow Text

A small C/raylib project created while learning game programming without a
full game engine.

It began as an experiment to draw rainbow-colored text. It has since acquired
movement, collision detection, and a disturbing awareness of its impending
collisions.

## Current Features

- Per-character animated rainbow coloring
- Frame-rate-independent movement
- Screen-edge collision detection
- Bouncing
- A melodramatic scream shortly before impact
- Crash sound effects on collision

## Planned Features

- Scream volume that increases as impact approaches
- Scream fade-out after impact
- Ease-in/ease-out movement near collisions
- Whatever other unnecessary features seem funny

## Built With

- C
- [raylib](https://www.raylib.com/)

## Building

This project requires raylib and a C compiler.

The project is currently developed on Windows using GCC and raylib.

## Controls

There are no controls.

You merely witness it.
